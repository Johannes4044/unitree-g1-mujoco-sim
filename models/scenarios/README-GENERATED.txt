Generated by scripts/build_scenarios.py from ../../scenarios/*.xml and ../g1_pick_place.xml.
Do not edit by hand.

Unlike the main repository, these files ARE committed here: this repo has to work after one
`git clone` (or one unzipped archive) on a machine with no network, so the built scenes are
vendored alongside the meshes rather than treated as build output.

Rebuild them (offline, a few seconds) after changing a scenario or an object:

    python scripts/build_scenarios.py                          # all
    python scripts/build_scenarios.py scenarios/house_rooms.xml
    python scripts/build_scenarios.py --seed 7                 # a randomised variant

Seeded variants (<name>_s<seed>.xml) are yours to keep or delete; nothing depends on them.
